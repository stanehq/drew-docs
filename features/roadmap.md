# Roadmap

These modules are planned. Their settings already exist in the [schema](https://api.drewbot.xyz/api/v1/schema) with `enforced: false`, so you can prepare them, but they have **no effect yet**.

- **Anti-spam**: message rate limits with punishments.
- **Automod**: invite and link filters.
- **Anti-bot**: block unverified bots and very new accounts.
- **Recovery**: restore deleted channels and roles after a nuke.
- **Beast mode**: maximum strictness for every protection.
- **Quarantine**: strip roles from punished users instead of removing them.
- **More anti-nuke coverage**: bans, kicks, webhooks, emojis, vanity URL, server settings and dangerous permissions.
- **Raid lockdown**: lock the server and apply slowmode during a raid.

Follow the [changelog](../changelog/v.1.x/v.1.0.0.md) and our [support server](https://discord.gg/5e2jm7QDSS) for release news.
