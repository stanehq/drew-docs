# Verification

Members press a button on a panel and Drew gives them a role. Combine it with channel permissions so new members only see your verification channel until they verify.

## Set it up

1. Create a role, for example `Verified`, and give it access to your server's channels.
2. Run `/verify setup role:@Verified channel:#verify`.
3. Post the panel with `/verify send`.

Drew's role must be **above** the verification role so it can assign it.
