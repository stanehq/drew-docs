# Backups

Save your configuration and restore it in seconds, for example before a big change or after an incident.

- `/bkp save` saves the current configuration with a category and an optional label.
- `/bkp list` shows your backups.
- `/bkp load` restores one.
- `/bkp delete` removes the backups in a category.

Backups require the Administrator permission. See [Backups commands](../commands/bkp.md) for every option.
