# v.1.1.0

## Configuration API

- Configure Drew from scripts or AI agents with per-server tokens: `/api token create`, `list` and `revoke`.
- Self-describing settings schema, dry runs, atomic changes and a full audit trail.
- See the [Configuration API](../../developers/api/intro.md).

## Website

- New dashboard: the server owner can change settings from the browser. Every change is logged.
- Public [status](https://drewbot.xyz/status) and [metrics](https://drewbot.xyz/metrics) pages.
- New [pricing](https://drewbot.xyz/pricing) page. Legal documents now live on [drewbot.xyz](https://drewbot.xyz/terms).

## Documentation

- Command reference rebuilt from the bot itself, so every command, option and permission is accurate.
- New pages for anti-nuke, anti-raid, verification, logging, SUDO mode, backups and the roadmap.
- Removed pages for modules that aren't available yet. They are listed on the [Roadmap](../../features/roadmap.md).
