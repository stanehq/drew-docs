# Verification

A one-click verification panel that gives members a role.

!!!info Who can use it
By default, members with **Manage Server**. Server admins can change this in Server Settings, Integrations.
!!!

## /verify setup

Setup the verification role and channel.

| Option | Type | Required | Description |
|---|---|---|---|
| `role` | Role | Yes | Role to assign upon verification |
| `channel` | Channel | Yes | Channel for the verification panel |

## /verify send

Send the verification panel.
